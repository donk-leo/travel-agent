# 武功山景区指南数据采集与预处理（项目1）

《数据挖掘》探索性实验 · 项目1 · 本人负责景区：**武功山（江西省萍乡市）**。

本仓库完成武功山景区官方推荐路线与游客游记的采集、正文抽取、清洗、结构化与质量验证，
产出可直接供项目2（实体识别）、项目3（路线层级挖掘）使用的数据集，并提供完整可复现脚本。

## 1. 数据概况

| 项目 | 结果 |
| --- | --- |
| 来源站点 | 5 个：萍乡武功山景区官网、豆瓣小组、8264 户外论坛、简书、搜狐号 |
| 记录总数 | 14 条（官方路线 6 条，游客游记 8 篇） |
| 有效记录 | 13 条（官方 6 条，有效游记 7 篇） |
| 原始 / 清洗后字数 | 15769 / 15134（去空白），整体删除率 4.03% |
| 时间跨度 | 2012-06-29 — 2026-10-06 |
| 采集日期 | 2026-10-28 |

其中 WGS-T-04 为图片为主的短帖（33 字），保留并标记 `文本过短/图片为主`，不计入有效游记。
有效游记 7 篇，满足任务书“每景区 ≥1 条官方路线、≥3 篇游记”的要求（任务书另写“游记各 5 篇”，
本项目实际可用 7 篇）。

## 3. 快速开始

环境：Python 3.11+（实测 3.12.14）、Windows 10/11。

```bash
pip install -r requirements.txt
python src/run_all.py            # 复用已抓取的 HTML，约 10–20 秒
python src/run_all.py --refresh  # 重新采集 14 个页面（约 40–60 秒，2 秒/页）
```

重新生成报告：

```bash
python report/make_figures.py
python report/build_report.py
```

## 4. 字段说明（主数据集）

| 字段 | 说明 |
| --- | --- |
| `doc_id` | 唯一编号：`WGS-O-xx` 官方路线，`WGS-T-xx` 游客游记 |
| `scenic_area` | 景区（武功山） |
| `doc_type` / `subtype` | 官方路线/游客游记；一日游/两日游/露营/徒步等 |
| `title` / `author` / `publish_date` | 标题、作者、发布时间（YYYY-MM-DD） |
| `source_site` / `source_url` | 来源站点与原始链接 |
| `extract_rule` | 正文定位规则 |
| `raw_content` | 正文抽取后、清洗前的文本（保留原始噪声） |
| `clean_content` | 清洗后文本（后续项目直接使用） |
| `char_raw` / `char_clean` | 去空白字符数 |
| `quality_flags` | 质量标记（分号分隔），如 `站点噪声已清理；作者缺失` |
| `is_valid` | 是否达到最低字数与信息量要求 |

完整字段见 Excel `03_字段字典`。

## 5. 清洗规则（R1–R8）

| 编号 | 规则 | 说明 |
| --- | --- | --- |
| R1 | HTML 残留 | 删除残余标签与实体 |
| R2 | 站点噪声 | 导航、按钮、版权、推荐、下载信息、日期行等整行删除 |
| R3 | 链接/联系方式 | 删除 URL、邮箱；以链接为主的行整行删除 |
| R4 | 表情/异常符号 | emoji、零宽字符、控制符；键帽数字还原为“1. ” |
| R5 | 空白/换行 | 统一换行、压缩空格、去连续空行 |
| R6 | 标点/字符宽度 | 全角字母数字转半角、合并重复标点、去汉字间空格 |
| R7 | 段落去重 | 完全重复 + 相似度 ≥0.90 的重复段落 |
| R8 | 编码/空值 | 删除 U+FFFD；作者/日期缺失记“未知”并打标 |

规则参数（相似度 0.90、噪声行长 50、有效字符比例 0.35 等）及边界说明见实验报告 3.4 节。

## 6. 质量结果

- 官方路线 6 条全部有效；游记 8 篇中 7 篇有效（1 篇图片帖标记无效）。
- 作者缺失 2 条（简书页面未提供作者字段）；日期缺失 0 条。
- 文档级完全重复 0 条、高度相似 0 条、编码替换符 0 个。
- 清洗共删除噪声行 18 行、表情符号 50 个、链接 1 个、重复段落 2 段。
- 详细逐篇指标见 `outputs/质量检查报告.md` 与 Excel `04_质量检查`。

## 7. 小组三景区合并

三位成员各自交付 `data/processed/<景区>_guides.csv` 后，放到同一目录并运行：

```bash
python src/merge_group.py
```

脚本会校验字段、按 `clean_hash` 去重，生成 `outputs/三景区汇总数据集.csv` 与
`outputs/三景区汇总统计.csv`；不足 3 个景区时会提示补齐。

## 8. 合规与限制

- 仅采集公开可访问页面，请求间隔 2 秒，不绕登录、不请求非公开接口；数据仅用于课程实验，
  版权归原作者/平台所有，引用请标注来源链接。
- 马蜂窝（登录验证）、Trip.com（繁体 + 前端 JSON 渲染）未纳入，原因记录在
  `config/sources_rejected.csv`。
- 站点规则绑定当前页面结构；页面改版时可用文本密度兜底，但正文完整度可能下降。
- 图片说明等短图注仍可能残留，建议在项目2用停用词/词性过滤处理。
