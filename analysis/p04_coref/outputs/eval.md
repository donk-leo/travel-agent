本文件由 `src/eval_coref.py` 根据 `outputs/annotations.csv` 与 `outputs/coref.jsonl` 自动生成，数字可复算。

## 1. 指标定义

- **准确率 accuracy** = 判断正确的标注条数 / 标注总数；空 gold + 空预测记为正确（识别出“无明确先行词”）。
- **标注覆盖率 coverage** = 模型给出非空先行词的标注条数 / 标注总数。
- **精确率 precision** = 正确且非空的条数 / 模型给出非空先行词的条数。
- **召回率 recall** = 正确且非空的条数 / gold 非空的条数。
- **全量消解率** = `coref.jsonl` 中 antecedent 非空条数 / 全部代词条数 = 28/140 = 20.00%。

## 4. 错误分析

- **CL-O-03 这里@268**：gold=`尖叫地带`，预测=`北门`。句子：从北门进的话第一站就是尖叫地带啦，我们将在这里开启尖叫路线，为广州长隆欢乐世界之旅开一个好头～Follow me～
- **BYS-T-04 这里@599**：gold=`摩星岭南门`，预测=`摩星岭`。句子：从山顶广场接着沿云山南路向北走，我们在「九龙泉牌坊」处走左侧小路，路过「九龙泉」-「广州碑林」-「爬山廊」-「观云阁」后再次回到马路上，再走一小段即可到达「摩星岭南门」，在这里买票进入后走台阶即可到达摩星岭最高点
- **WGS-O-06 这个@1190**：gold=`吊马桩`，预测=`武功山`。句子：大概1个小时不到就可以到达吊马桩，这个地方是高山和草甸的分界线，在这往下看是峻峭山峰，往上走是柔软的草甸。
- **WGS-T-05 这里@2446**：gold=`几字湾栈道`，预测=`武功山`。句子：这里是回望武功山整条山脊线的绝佳观景位。

四类典型错误：
1. **P2 漏标 / 归一化偏差**：如“十环过山车”被漏标，最近的“垂直过山车”被误选；P3 只补到部分 POI。
2. **后置指代**：`这里` 的先行词出现在代词之后（“第一站就是尖叫地带……我们将在这里”），最近前文规则天然看不到。
3. **人物/动物/事件指代**：`他们`、`它`（蚊子）、`这`（瞬间）在 schema 中没有 PERSON/ANIMAL/EVENT 类型，宁可不消解。
4. **路线/集合指代**：`这条`、`这些` 指向路线或复数集合，P4 schema 没有 ROUTE/集合类型，规则选择留空。

## 5. 结论

规则在 20 条人工标注上准确率 80.0%、精确率 75.0%；主要收益来自“同句/近邻 POI + 类型白名单”，主要损失来自 P2 漏标和后置指代。
因此本方法定位为**高精度、可解释的基线**：宁可 `needs_review=true` 留空，也不把时间/人物/路线硬映射成 POI；后续可用 LLM 或模型对未消解项做二次判定。
