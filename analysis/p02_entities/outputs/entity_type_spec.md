# 项目 2 · 景区游览步骤实体定义规范表

## 1. 适用范围与统一原则

本规范面向长隆、广州白云山、武功山三类景区的攻略文本，且仅从 P1 已清洗的
`clean_content` 中抽取实体。三个景区使用同一套 `POI / TRANSPORT / TIME` 类型体系；
景区专名的差异通过词典中的 `scenic_area` 和 `normalized_name` 处理，不另设新类型。

统一判定原则：

1. 只记录文本中实际出现的连续字符串；`char_start`、`char_end` 必须能从原文精确回取。
2. 同一位置存在重叠候选时，优先保留更完整的表达。例如保留“地铁3号线”，不同时保留其中的“地铁”。
3. 同一实体的简称、别名可保留原始 `entity_text`，但用 `normalized_name` 统一指向标准名称。
4. 只抽取与游览、到达、移动或行程安排直接相关的内容；不因词面像景点、交通或时间就一律收录。

## 2. 实体定义规范表

| 类型 | 定义 | 应识别的范围 | 不识别/边界 | 正例 | 易混淆情况与判定 |
|---|---|---|---|---|---|
| `POI` 景点 | 在景区内外可被定位、参观、经过或作为路线节点的专名地点、设施、园区、游乐项目、餐饮点及入口。 | 景区全称/简称、子园区、山峰、寺庙、路线节点、索道站、餐厅、游乐项目、景区门口。 | “景区、园区、路线、地方、这里”等泛称；只描述感受的普通名词；没有专名意义的“入口/出口”。 | “长隆欢乐世界”“摩星岭”“观音宕”“金顶索道”“白虎餐厅”“北门”。 | “索道”单独出现表示交通方式，归 `TRANSPORT`；“金顶索道”是具名设施，归 `POI`。`北门`在长隆词典中是明确入口，归 `POI`；孤立的“入口”不抽取。 |
| `TRANSPORT` 交通方式 | 用于到达景区、景区内换乘或游览移动的交通工具、移动方式及具名公共交通线路。 | 地铁及线路、公交、大巴、观光车、小火车、索道、缆车、自驾车、步行、徒步。 | 普通动作词，如“到达、前往、转乘”；停车场、车站等地点名（应按具名地点处理）；与游览无关的“训练徒步”。 | “地铁3号线”“公交”“观光车”“索道”“徒步”“自驾车”。 | “汉溪长隆地铁站”如进入词典，应为地点 `POI`；“地铁3号线”是线路 `TRANSPORT`。`徒步`是移动方式，但若上下文是出行前健身训练，应人工标注为边界样例，不作为游览步骤证据。 |
| `TIME` 时间节点 | 能表达出发、到达、停留、游览顺序、开放时段或行程时长的明确时间信息。 | 具体时刻、时段、日期/节假日、行程第几天、时长、时间范围、日出日落。 | “很久、尽快、经常”等模糊时间词；与游览无关的年龄、年份、价格；无时间含义的数字。 | “12:10”“上午”“第二天”“3-4H”“15分钟”“五一”“日出”。 | “一小时”若描述到达、步行或游玩用时，归 `TIME`；若描述出行前训练，则保留为边界样例并在质量检查中说明。`12:10`是具体时刻，确定归 `TIME`。 |

## 3. 跨景区一致性说明

| 场景 | 统一处理方式 | 示例 |
|---|---|---|
| 景区全称与简称 | 都识别为 `POI`，再归一化到同一个标准名称。 | “白云山” → `normalized_name=广州白云山`；“武功山” → `normalized_name=武功山`。 |
| 具名游览节点 | 无论是山峰、寺庙、游乐项目还是园内区域，均为 `POI`。 | “金顶”“能仁寺”“超级大摆锤”。 |
| 通用交通表达 | 跨景区统一为 `TRANSPORT`，不因出现地点不同改变类别。 | “地铁”“公交”“索道”“徒步”。 |
| 时间表达 | 跨景区统一为 `TIME`，由自定义词典或正则规则抽取。 | “早上”“第二天”“9:00-12:00”“30分钟”。 |

## 4. 标注与输出约定

每条实体记录至少包含：原文实体 `entity_text`、归一名称 `normalized_name`、类型 `entity_type`、
景区 `scenic_area`、文档编号 `doc_id`、字符位置 `char_start/char_end`、所在句 `sentence`、
抽取方法 `method` 和置信度 `confidence`。

示例：

```json
{
  "doc_id": "CL-T-01",
  "scenic_area": "长隆",
  "entity_text": "五一",
  "normalized_name": "五一",
  "entity_type": "TIME",
  "char_start": 6,
  "char_end": 8,
  "method": "rule"
}
```

## 5. 本轮质量控制中的典型边界

1. “观音宕、好汉坡、滴水观音、飚水瀑布、尽心瀑”在人工抽检中发现原词典未覆盖，已补入武功山 POI 词典并重新识别。
2. “地铁3号线、地铁5号线”由泛化的“地铁”细化为具体线路，类型仍为 `TRANSPORT`，实体总数不必增加。
3. 交通工具与具名交通设施按“是否为可定位专名”区分：`索道`为 `TRANSPORT`，`金顶索道`为 `POI`。
4. 所有边界判断都以攻略中的游览语境为准，人工抽检结论见 `manual_review_report.md`。
