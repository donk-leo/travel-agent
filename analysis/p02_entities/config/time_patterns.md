# 时间实体规则

时间实体由 Jieba 词典与正则规则共同识别。正则优先于单个“小时”“分钟”等泛词，以避免把没有完整边界的单位误识别为时间节点。

| 模式 | 示例 | 是否抽取 |
|---|---|:---:|
| 时刻 | `09:00`、`8:30前` | 是 |
| 时间区间 | `9:00-12:00`、`10:00–22:00` | 是，作为一个整体 |
| 游览时长 | `3-4小时`、`7小时内`、`两天一夜` | 是 |
| 日程索引 | `第一天`、`第二天`、`3天2夜` | 是 |
| 时段 | `上午`、`中午`、`下午`、`晚上`、`早上` | 是 |
| 自然时间节点 | `日出`、`日落` | 是 |
| 日期/季节区间 | `6月-10月`、`五一`、`周末` | 是，但标注为计划时间，不推断具体日期 |
| 孤立单位 | `小时`、`分钟`、`当天` | 否 |

同一位置命中“时间区间”和其中的单个时刻时，只保留更长的时间区间，避免重复计数。
