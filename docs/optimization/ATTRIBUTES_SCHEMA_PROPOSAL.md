## 3. 列定义（9 列，顺序固定）

| # | 列 | 类型 | 约束 | 说明 |
|---:|---|---|---|---|

## 4. 十个属性的口径（含正例/反例）

> 总原则：**只在原文明确写出时产出**；“建议/约/不少于/实测/官方”等口径必须能从 evidence 读出。**未知不产出**，不为覆盖率补齐。

### 4.1 `opening_hours`（开放/运营时段）
- 定义：园区、景区或**园内设施**对外运营的时间点/时段，含开园、运营时段、首末班（明确写“运营时间”时）、末班入场。
- `value`：时间点/时段；**非园区级**时加主语前缀（如 `索道 9:00-18:00`），与 D0 写法一致；`unit` 空。
- 正例：`9点开园`→`9:00`；`开放：南门/西门24小时`→`南门/西门 24小时`；`8:30-12：00\n13:00-18:00`→`航空营地 8:30-12:00、13:00-18:00`。
- 反例（**不得**入本属性）：行程站序（`09:00 入园`）、个人作息（`5:30 起床`）、交通发车时刻（`首车6:00 末车17:30`，属 §9 的 `transport_schedule` 缺口）、最佳游览时间（`9:00前/16:00后`）。
- 与 `suggested_duration` 严格分离：`建议 2–3 小时` **永远不写成本属性**。

### 4.2 `suggested_duration`（建议/标称游览时长）
- 定义：原文给出的游览、路线、往返、单段用时（含官方“游览时间不少于 X”和游记“耗时 X”）。
- `value`：数字或区间；`unit`：`小时`/`分钟`。**适用对象看 evidence**（如“下山全程 3-4 小时”不得读成景区总时长）。
- 正例：`3-4小时 | 索道单程25元`→`3-4` 小时；`可以在7小时内完成往返`→`7` 小时；`游览时间不少于3小时`→`3` 小时。
- 反例：索道乘坐 10 分钟、4D 影片 10 分钟等**设施体验时长**；机场快线 1 小时 15 分钟等**交通耗时**；`3-4H` 可收（H=小时），但 evidence 必须含 H。
- 口径（约/不少于/以内/实测）不并入 `value`，由 evidence 表达；实测值 confidence ≤0.8。

### 4.3 `ticket_price`（门票价）
- 定义：**景区/园区/子景区大门票**的票价（成人票、当日价、提前购优惠价、联票）。
- `value`：数字（保留原文小数位如 `100.0`）；`unit`：`元`。
- 正例：`门票：进山5元`→`5`；`门票70/人`→`70`；`门票：100.0（含欢乐世界、水上乐园、野生动物世界）`→`100.0`。
- 反例（**本版不收**，见 §9 缺口）：索道票、观光车票、停车费、园内餐饮/住宿/优速卡、`5折` 折扣率、`学生半价` 无绝对价。
- 同文档多价（当日 70 / 提前 60）**保留两行**，不合并、不取平均。

### 4.4 `transport_mode`（交通方式）
- 定义：到达景区/园区的方式，或园内具名移动方式（地铁/高铁/公交/大巴/机场快线/自驾/出租/网约车/包车/拼车/接驳车/转运车/索道/缆车/观光车/小火车/滑索）。
- `value`：方式名，可带线路号/站点（如 `地铁3号线汉溪长隆站D出口`）；`unit` 空。
- 正例：`只有乘坐免费的转运车才能去石鼓寺坐索道上山`→`免费转运车`；`南门→11号线云台花园站；西门→2号线萧岗站`→`地铁11号线云台花园站/2号线萧岗站`。
- 反例：纯步行（`沿百步梯步行游览`）、把“索道票价”句当交通、把体验项目（直升机观光/滑翔伞体验）当交通。

### 4.5 `suitable_for`（适合人群）
- 定义：原文明确写“适合/首选/XX党/XX玩家/老少皆宜/情侣/亲子”等的目标人群。
- `value`：人群短语；`unit` 空。
- 正例：`适合全家一起体验`→`全家`；`挑战硬核线（徒步党）`→`徒步党`；`适合怕累、带娃、老人`→`怕累/带娃/老人`。
- 反例：营销修辞无对象（`真的太爽啦`）；人群是**叙述者**而非建议对象（`我们一家三口`）——除非原文明确“适合”。

### 4.6 `height_limit`（身高阈值：准入/购票）
- 定义：原文以**身高**表述的准入或购票阈值（免票/半价/限乘），`unit`：`米`；原文写 cm 时保留 `厘米` 且不换算。
- 正例：`1.2米以下儿童免票`→`1.2` 米；`身高1.2m-1.5m儿童可享受门票5折优惠`→`1.2-1.5` 米。
- **口径声明（需过审，见 C3）**：包含“购票优惠阈值”，不只是游乐设施限乘。长隆 8 篇全文无任何身高数字 → **0 行**（不臆造 1.2/1.4m）。

### 4.7 `age_limit`（年龄阈值：准入/购票）
- 定义：原文以**年龄**表述的准入或购票阈值，`unit`：`岁`。
- 正例：`60-64 岁老人和学生及未成年人 2.5 元`→`60-64` 岁；`65 岁以上老人和 1.2 米以下儿童免票`→`65` 岁。
- 反例：`熊猫三宝今年就10周岁`（动物生日）、`80岁的“杖朝”老人`（同行者描述，非建议/限制）。

### 4.8 `meal_spot`（餐饮点）
- 定义：原文具名或可定位的餐饮点/餐饮区域（餐厅、酒楼、农庄、快餐、糖水铺、豆腐花店、烧烤区）。
- `value`：店名/区域名；`unit` 空。
- 正例：`推荐南国茶餐厅吃正宗的广式烧味饭`→`南国茶餐厅`；`餐：景鸿葡萄农庄`→`景鸿葡萄农庄`。
- 反例：泛化“带干粮/补给点很多/山上物价偏高”无具名点；住宿点（客栈/酒店）除非原文明确用餐。

### 4.9 `rest_spot`（休息点）
- 定义：原文明确用于休息/休整/歇脚的地点（亭子、广场、站点、客栈、餐厅内、影院）。
- `value`：地点名；`unit` 空。
- 正例：`我们寻得山间亭子驻足避雨、休整补给、解决午餐`→`山间亭子`；`到山顶广场，休整后前往摩星岭方向`→`山顶广场`。
- 反例：仅“住宿/露营”（`晚上住在金顶睡帐篷营地`）——除非同句有休息语义；泛化“配套设施齐全”。

### 4.10 `season`（适宜季节）
- 定义：原文明确建议的适宜/避开季节。
- `value`：季节短语（`春秋两季`、`夏秋`）；`unit` 空。
- 正例：`建议选择春秋两季，避开夏季的暴雨和冬季的严寒`；`很适合夏秋季节来体验`。
- 反例：营销句（`夏日必打卡`、`夏天的正确打开方式`）——v1 不收，避免把广告当季节建议。

### 4.11 `confidence` 评分口径（**抽取置信度 ≠ 来源权威度**）
| 值 | 含义 | 例 |
|---:|---|---|
| 1.0 | 规则直命中：原文完整给出值 + 口径 + 主语 | `门票70/人`、`9:00开园`、`适合全家一起体验` |
| 0.9 | 需一步归一化（补单位/跨行拼主语/全角冒号归一） | `门票：100.0（含…）`（无“元”字）、跨 3 行的观光车运营时段 |
| 0.8 | 主体或范围依赖邻近上下文 | `休整后`→休息点、免票身高阈值 |
| 0.6 | 分段/实测值映射为建议时长，或需跨句推断 | `下山要5小时`、`在此充分休整`→羊狮慕小火车站 |
| ≤0.5 | 不产出 | — |

来源权威度由 `doc_type` 承担（官方路线 / 游客游记 / 站点攻略），**不得**用 confidence 表达；T1.6 证据卡必须同时展示 `doc_type` 与 `publish_date`（时效，见 DATA_GAPS §3.1）。

## 5. `unknown` 的表达（v1 决策 + 待审）

- **v1：缺行 = 未知。** 不产出 `value` 空行，因为空值行**没有可锚定的 evidence**，会直接违反“无出处字段 = 0”。因此 `unknown_reason` 列在 v1 恒为空。
- 影响：`doc×attr` 无行即“原文未写”。T2.2/T2.3 查询时按“无行 → unknown”处理，**不得**回退到常识默认值。
- 已确认的“看似有、其实没有”：长隆身高/年龄限制 0/8；全部 32 篇**无闭园时刻与停止入场时间**；长隆官方 3 篇无票价数字。
- 备选（**需过审，见 C5**）：新增 `attr=unknown` 行或允许 `value` 空 + `unknown_reason`，同时把校验放宽为“有值行必须有 evidence，无值行可无 evidence”。本提案不建议 v1 采用。

## 6. 机器校验规则（脚本 `--verify` 已实现，父 Agent 可复跑）

1. 表头与顺序 = 本文 §3 九列。
2. `attr ∈` 10 值白名单；`unit ∈ {元,分钟,小时,米,厘米,岁,空}`。
3. `doc_id` 存在于对应 `<area>_guides.csv`。
4. `clean_content[char_start:char_end] == evidence_text`（**逐行、逐字符**）。
5. `evidence_text` 非空；且命中该属性的判定正则（如 `ticket_price` 的 evidence 必须含“门票/票价/成人票/元每人”）。
6. 有值行 `unknown_reason` 为空；v1 无空值行。
7. 同一 `(doc_id, attr, char_start, value)` 不得重复；同 `doc_id+attr` 不同值**必须**多行保留。
8. `0.0 ≤ confidence ≤ 1.0`。
