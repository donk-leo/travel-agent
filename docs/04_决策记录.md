# 04 · 决策记录（ADR）

> 记录“为什么这么做”，避免后来的人（或 Agent）反复推翻已经定好的事。
> 格式：背景 → 决定 → 后果。新增决策追加编号，不改旧编号。

---

## ADR-001 采用武功山的 24 列作为组标准，而不是我自己的 20 列

- **背景**：HappinessJo 的长隆数据用 20 列英文结构（`raw_text/clean_text/raw_len/...`），
  T0coke 的武功山用 24 列（`raw_content/clean_content/char_raw/...`）。两套不兼容。
- **决定**：以武功山 24 列为全组标准。理由：① 已落地并有合并脚本 `merge_group.py` 按它校验；
  ② 多出的 `clean_hash`、`quality_flags`、逐规则计数是合并与质检需要的；③ 改一套已验证的比改两套便宜。
  长隆数据通过 `scenic/changlong/src/export_standard.py` 转换。
- **后果**：长隆的历史产物（`experiment1_chimelong/`）保留为工作副本，但**入库必须是转换后的 24 列**；
  任何字段语义变化都要先改本 ADR 再改代码。

## ADR-002 目录与文件名用 ASCII

- **背景**：原有 `武功山/` 等中文目录在 PowerShell 输出、Git 转义、URL 编码上反复出问题。
- **决定**：新建目录一律小写 ASCII（`scenic/wugongshan/`、`analysis/p02_entities/`）；
  人类可读性由 README 与中文文档承担。
- **后果**：迁移时需修正文档内相对链接（见 `05_迁移记录.md`）；中文只出现在文档标题与正文里。

## ADR-003 项目 1 放 scenic/，项目 2–7 放 analysis/

- **背景**：目录原来只按景区切，而项目 2–7 是跨景区的分析。
- **决定**：`scenic/` 只放“一人一景区”的数据与报告；`analysis/pNN_*/` 放跨景区、唯一实现的分析代码。
- **后果**：三个人不再各写一套实体识别；代价是 p02 起需要同时读三份数据，输入契约必须显式列出（已写进 handover）。

## ADR-004 用 handover.yaml + git tag 作为交接契约

- **背景**：口头交接容易漏项，且 Agent 无法读取聊天记录。
- **决定**：每个项目一份 `standards/handover/pNN_*.yaml`，写明 inputs / outputs / checks / frozen / acceptance；
  交付时打 tag，下游按 `from_tag` 引用。
- **后果**：交接从“说一声”变成“可校验”；代价是每个项目要维护一份 YAML（约 30 行）。

## ADR-005 一个项目一个 owner，owner 不兼 reviewer

- **背景**：三人规模下最容易出现“自己写自己验”。
- **决定**：每个项目指定唯一 owner 与独立 reviewer（矩阵见 `03_交接标准.md` 第 1 节）。
- **后果**：复核人必须在 PR/交接卡上留名；代价是每个人要多看一个项目。

---

## ADR-006 旧的根目录采集产物归档而非删除

- **背景**：根目录原有 8 个文件（`采集.py`、`采集结果.csv/json`、小红书相关），
  其中含长隆欢乐世界 10 条可用数据，但类型值不合规范。
- **决定**：整体移入 `archive/legacy_collect_2026-10-28/`，不参与合并；需要时用转换脚本重标类型再入库。
- **后果**：仓库根目录清爽；代价是多一层 archive 目录，需要 README 说明其性质。

## ADR-007 报告 docx 单点维护，章节稿分散存放

- **背景**：docx 是二进制，两人同改必然互相覆盖，且无法合并。
- **决定**：章节稿放各自项目 `report/`；总报告 `report/总报告_*.docx` 只有组长改；
  统一模板见 `report/模板/`。
- **后果**：组员要按模板写章节；代价是需要一次格式对齐（标题层级、表题图题、字号）。

---

## ADR-008 不搭 CI，用本地 check 脚本

- **背景**：三人小项目，搭 GitHub Actions 的收益低于维护成本。
- **决定**：质量门用 `checks/check_pNN_*.py` 本地执行；PR 模板里要求粘贴运行结果。
- **后果**：依赖成员自觉；缓解手段是交接 checklist 与 reviewer 复核。
