## 4. 回滚方式

```powershell
# 查看重整前状态
git log --oneline v0.1-p01-pre-restructure -3

# 整体回滚到重整前（会丢弃 main 上的重整提交，慎用）
git checkout main
git reset --hard v0.1-p01-pre-restructure
git push --force-with-lease origin main       # 仅在确认无人依赖时使用

# 只回滚某个文件
git checkout v0.1-p01-pre-restructure -- 武功山/
```

> 若只是个别目录有问题，优先用 `git revert <commit>` 生成一次反向提交，避免改写历史。
