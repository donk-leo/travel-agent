## 为什么不直接进主数据集

1. **字段不合规**：`类型` 列用了 `游客攻略（去哪儿）`、`官方资料`，不在 `官方路线 / 游客游记 / 站点攻略` 三个合法值内；
2. **缺合并必需列**：没有 `clean_content`、`source_site`、`is_valid` 等；
3. 与三景区主数据集（24 列）结构不同，直接合并会破坏 `merge_group.py` 的校验。

## 如何复用

- **去哪儿/白云山/长隆欢乐世界的游记类内容**：按 `docs/01_统一规范.md` 第 5 节转换，
  重标 `doc_type`（站点编辑内容标 `站点攻略`），补 `clean_content` 与 `clean_hash` 后才能入库；
- **失败记录**：直接引用到对应景区的 `outputs/质量检查报告.md` 与报告的“问题与分析”章节；
- **小红书数据**：需登录态，复现性差，若要入库必须在 README 标注“仅本人可复现”。
