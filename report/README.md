# 报告装配区

> 总报告 `report/总报告_第X组.docx` **只有组长修改**；其他人只交自己项目的章节稿。
> 章节稿位置：`analysis/pNN_*/report/` 或 `scenic/<area>/report/`。

## 目录

| 路径 | 用途 |
|---|---|
| `模板/章节模板.docx` | 统一排版：标题层级、表题在表上方、图题在图下方、字号与行距 |
| `章节/` | 各项目章节稿收集处（组长合并前暂存） |
| `总报告_第X组.docx` | 最终提交文件（组长维护） |

## 统一排版约定（避免三份稿子拼起来打架）

1. 正文：宋体小四（12pt），行距 1.5 倍，首行缩进 2 字符；
2. 标题：一级 15pt 黑体、二级 13pt、三级 12pt，加粗；
3. 表题放在表格**上方**，格式 `表 1-1 标题`；图题放在图**下方**，格式 `图 1-1 标题`；
4. 表格用固定列宽 + 表头灰底，跨页时表头重复；
5. 图表编号按项目连续（项目 2 用 `表 2-1`、`图 2-1`）；
6. 每章末尾必须有一节“问题与分析”，记录真实失败与限制。

## 合并流程（组长）

```powershell
# 1) 收集各项目章节稿到 report/章节/
# 2) 按项目顺序拼装：封面 → 小组信息 → 共同要求 → 项目1..7 → 总结反思 → 附录
# 3) 统一编号与目录，检查图表引用是否与正文一致
# 4) 导出 PDF 备份，随 docx 一起提交
```
